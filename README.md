# Генерация и распознавание потоков событий

## 1. Назначение работы

В работе рассматриваются пять моделей потоков событий: рекуррентные потоки с гамма-распределением (`gamma_renewal`) и распределением Вейбулла (`weibull_renewal`), MMPP с двумя (`mmpp_2`) и тремя (`mmpp_3`) состояниями, а также MAP с двумя состояниями (`map_2`).

`generate_traces.py` формирует по **10 000 событий** для каждой модели на основе параметров из `model_parameters.json`. `analyze_traces.py` определяет тип потока **только по наблюдаемым временам событий**, не зная параметров генерации.

## 2. Формат хранения трасс (CSV)

Для каждой модели создаётся отдельный файл в папке `traces/`: `gamma_renewal.csv`, `weibull_renewal.csv`, `mmpp_2.csv`, `mmpp_3.csv`, `map_2.csv`.

CSV-файлы сохраняются в кодировке **UTF-8** с разделителем **запятая**. Первая строка содержит названия столбцов; далее идут 10 000 строк с событиями.

| Столбец | Значение |
|---|---|
| `event_id` | Порядковый номер события, от 1 до 10000. |
| `event_time` | Время наступления события относительно начала моделирования (`t = 0`). |
| `interarrival_time` | Время между текущим и предыдущим событиями; для первого — время от `t = 0`. |

## 3. Гипотезы H1–H5

Гипотезы проверяются **по очереди**. При принятии гипотезы дальнейшие проверки прекращаются.

| Гипотеза | Модель | Условие принятия |
|---|---|---|
| **H1** | Gamma | `p_LB ≥ 0.05`, `p_KS(Gamma) ≥ 0.05`, `BIC(Weibull) − BIC(Gamma) ≥ 10`. |
| **H2** | Weibull | `p_LB ≥ 0.05`, `p_KS(Weibull) ≥ 0.05`, `BIC(Gamma) − BIC(Weibull) ≥ 10`. |
| **H3** | MMPP(2) | `p_LB < 0.05`, `min(BIC(MMPP3), BIC(MAP2)) − BIC(MMPP2) ≥ 10`. |
| **H4** | MMPP(3) | `p_LB < 0.05`, `min(BIC(MMPP2), BIC(MAP2)) − BIC(MMPP3) ≥ 10`. |
| **H5** | MAP(2) | `p_LB < 0.05`, `min(BIC(MMPP2), BIC(MMPP3)) − BIC(MAP2) ≥ 10`. |

Обозначения и критерии:

- **`p_LB`** — p-значение критерия Льюнга—Бокса для первых **10 лагов**. При `p_LB < 0.05` отвергается гипотеза об отсутствии автокорреляции интервалов. Значение `p_LB ≥ 0.05` не доказывает независимость.
- **`p_KS`** — p-значение критерия Колмогорова—Смирнова с **параметрическим бутстрэпом (99 повторов)**, проверяющего согласие с Gamma или Weibull после оценки их параметров.
- **`BIC`** — байесовский информационный критерий: `BIC = k · ln(n) − 2 · ln(L̂)`, где `k` — число оцениваемых параметров, `n` — объём трассы, `L̂` — максимальное правдоподобие. Меньшее значение предпочтительнее; для принятия требуется преимущество **не менее 10**.

Если не принята ни одна из гипотез H1–H5, программа выдаёт **«НЕОПРЕДЕЛЕННО»**.
